# Hi, I'm Heng 🎮

**Game mods & modding tools · Survivalcraft · Outer Space · C# / .NET**

I make mods for the games I play: new weapons, towers, mechs and companions, plus the maps, helpers and test tools that keep them working after a game update.

做游戏模组和模组工具：《生存战争》（Survivalcraft）的武器、防御塔、机甲、AI 同伴和地图，《秩序：新曙光》（Outer Space）的防御塔和跑商助手。
